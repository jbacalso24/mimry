What MIMRY builds for every task

One index of your repository, kept fresh as files change, and a few small outputs your agent can read in seconds.

A context pack your agent reads first

A short Markdown handoff with the files, key symbols, relationships, risky paths and a reading order. Relative paths, never source dumps.

## Suggested Reading Order
1. web/src/lib/payments.ts - primary code/edit path
2. web/src/features/checkout/useCheckout.ts - primary code/edit path
3. web/src/app/checkout/page.tsx - primary code/edit path

5. web/tests/checkout.test.tsx - test/verification support

Connect your agent

MIMRY runs as an MCP server, so agents call it directly. Add it once per machine.

claude mcp add --scope user mimry -- mimry-mcp

Teach it the workflow too: mimry install --project --platform claude-code --always-on --hooks

codex mcp add mimry -- mimry-mcp

Teach it the workflow too: mimry install --project --platform codex --always-on --hooks

{
  "mcpServers": {
    "mimry": { "command": "uvx", "args": ["mimry", "mcp"] }
  }
}

Skills are available for 20 agents, including Copilot CLI, Gemini CLI, OpenCode, Kiro, Amp and Devin. Run mimry install --list-platforms.

Then, on every task

  1. Start

    mimry preflight with the task prints the files to read first.

  2. Read the pack

    The context pack explains what ranked and how it connects.

  3. Navigate

    find, symbol, related and why replace broad searches.

  4. Verify

    Tests and build output stay the final truth.

  5. Record

    mimry feedback turns what helped into ranking signal.

Questions

What is MIMRY?

A local command-line tool and MCP server that gives AI coding agents a memory of a code repository. It answers "which files matter for this task?" with a ranked list, the reason each file ranked, and a written context pack.

Does MIMRY upload my code?

No. Everything runs on your machine. There is no code upload, no remote embedding service and no telemetry. The index lives in your user cache folder, outside the repo.

Which coding agents work with it?

Any agent that can run a shell command or use an MCP server, including Claude Code, Codex, GitHub Copilot CLI, Gemini CLI, OpenCode, Kiro, Amp and Devin.

Does it replace reading the code?

No. MIMRY narrows where to look. Source files, tests and build output stay the final truth, and every result says why it ranked so an agent can check it.

What does it need to run?

Python 3.11 or newer on Windows, macOS or Linux. Install it with uv tool install mimry or pipx install mimry.

How much does it cost?

Nothing. MIMRY is open source under the MIT license.
