MIMRY / Claude Code setup

Set up MIMRY for Claude Code

Give Claude Code a local repository map before it edits: a callable MCP server plus project instructions that require focused preflight, source inspection, and real verification.

Install and connect

  1. Install MIMRY

    uv tool install mimry
mimry --version

    Python 3.11 or newer is required. pipx install mimry is also supported.

  2. Register the MCP server

    claude mcp add --scope user mimry -- mimry-mcp
claude mcp get mimry

    This is the same Claude Code CLI registration used by MIMRY's integration smoke test. It runs the installed mimry-mcp stdio server locally.

  3. Install the project workflow

    cd /path/to/your/repo
mimry install --project --platform claude-code --always-on --hooks
mimry install --project --platform claude-code --status

    The project install writes the MIMRY skill under .claude/skills/mimry/. --always-on adds a bounded MIMRY block to CLAUDE.md; --hooks adds the supported first-search reminder. Review generated files before committing them.

  4. Start a real task

    mimry preflight "fix the login redirect bug"
# Read .mimry/mimry-out/context/latest.md

    Use a specific task, not a generic word such as “frontend.” Preflight sets up and refreshes the index when needed, then writes the context pack and prints the first files to inspect.

Project or user scope?

Project scope

Use --project when the workflow rules should travel with one repository. This writes project files that a team can review.

User scope

Omit --project to install the MIMRY skill for your user account. MCP registration is user-scoped for Claude Code.

Removing it: run mimry uninstall --project --platform claude-code --always-on --hooks for the matching project install. Run claude mcp remove --scope user mimry only if you also want to remove the MCP registration.

What Claude Code should do next

  • Read .mimry/mimry-out/context/latest.md before opening unrelated files.
  • Use mimry find, mimry symbol, mimry related, mimry why, or the equivalent MCP tools for follow-up navigation.
  • Open the selected source and repo rules. MIMRY rankings are navigation evidence, not proof.
  • Run the repository's real tests or build, then record useful ranking feedback.
